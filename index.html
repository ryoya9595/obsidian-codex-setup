Codex はじめての導入マニュアル

自分専用のAI秘書が、
前回のことを覚えてる。

フォルダを1つ作って、Codex にこのページのURLを貼るだけ。「おはよう」で今日やることを出してくれて、セッションが変わっても前回の続きを覚えているあなた専用のAI秘書ができあがります。秘書が書いた記憶は、無料のメモアプリ Obsidian で読んだり直したりできます。

所要時間 約10分 🍎 Mac / 🪟 Windows Obsidian は無料・登録不要

  2. 下の「コピー」を押して、このページのURLをコピー → そのフォルダを開いた Codex に貼り付けて送信

01

これは何？ — 記憶を持ったAI秘書をつくる

Codex は、新しいセッションを始めるたびに前回の内容を忘れます。毎回ちがう担当者に、最初から説明し直しているようなものです。

この仕組みを入れると、Codex がセッションの最初に記憶フォルダを自分で読み、作業の区切りで自分で記録するようになります。さらに、名前とキャラをあなたが決めたAI秘書として、やることの管理や1日の段取りを手伝ってくれます。

BEFORE

毎回ゼロから説明

「前回の続きなんだけど、〇〇をやってて、今こういう状況で…」
「すみません、その件は分からないので詳しく教えてください」
AFTER

ひとことで再開

「おはよう」
「おはよう！今日はこの3つがおすすめ。①昨日やり残した〇〇 ②期限が近い△△ ③… どれからやる？」

🗂 仕組み — 1つのフォルダを、2つのアプリで見る

Codex記憶を読む・書く（自動）
⇄
Obsidian記憶を人が読む・直す

どちらもあなたが作った同じフォルダを見ているだけ。中身はただのメモ（テキストファイル）です。Codex はフォルダの中の AGENTS.md というファイルを毎回最初に読むので、そこに「記憶の読み書き」と「秘書の仕事」のルールを書いておきます。

あなたのフォルダ/
├── AGENTS.md     … AIが毎回最初に読むルール
├── about-me.md   … あなたのプロフィール（呼び方・目標）
├── secretary.md  … AI秘書の設定（名前・性格・話し方）
├── todo.md       … やること（優先度つき）
├── daily/        … 日報（その日やったこと・決めたこと）
├── projects/     … 取り組み中のことの「今どこ・次なに」
├── decisions/    … 大事な判断の記録
├── mistakes/     … ミスの記録 → 同じミスを繰り返さなくなる
└── ideas/        … アイデアのメモ
💡Claude Code 版で記憶フォルダを作った人は、同じフォルダを Codex で開いてURLを貼ればOK。今の記憶はそのままで、Codex でも同じ秘書・同じ記憶が使えるようになります。
02

準備 — 記憶用のフォルダを1つ作る

✅フォルダをもう作ってある人は STEP 2 へ（講師と一緒に作った人など）。

STEP 1　フォルダを作る

名前は AI-Brain のような英数字がおすすめです（日本語やスペースは避けると安心）。

🍎 Mac

Finder で作る

Finder を開く → 左の「書類」→ 何もないところを右クリック →「新規フォルダ」→ 名前を AI-Brain にする

🪟 Windows

エクスプローラーで作る

エクスプローラーを開く → 左の「ドキュメント」→ 何もないところを右クリック →「新規作成」→「フォルダー」→ 名前を AI-Brain にする

⚠️「書類」「デスクトップ」「ダウンロード」そのものは選ばないでください。中の全ファイルが記憶として読み込まれてしまいます。必ず新しく作ったフォルダを使います。

STEP 2　Codex でそのフォルダを開く

  • Codex アプリ：「フォルダを開く」（またはプロジェクトを追加）で、今作った AI-Brain を選ぶ
  • VS Code などのエディタ：「フォルダーを開く」で AI-Brain を開いてから Codex を使う
  • ターミナル：AI-Brain に移動してから codex を起動
💡「このフォルダを信頼しますか？」と聞かれたら「信頼する」でOK。Mac で「アクセスを許可しますか？」と出たら「許可」でOK。Obsidian はまだ入れていなくても大丈夫です（導入の途中で Codex が確認して、入れ方を案内してくれます）。

05
使い方 — 使うほど賢くなる

  

    
🌱 ふだんの使い方

    

      
こんなときこう言う

      
1日の始まり「おはよう」→ 今日やることを優先順に3つ出してくれる

      
やることが増えた「todoに〇〇を追加して」（期限があれば一緒に）

      
終わった「〇〇終わった」→ 完了にして、次にやることを提案

      
思いついた「メモして：〇〇」→ アイデアとして保存

      
1日の終わり「おつかれ」→ 今日のまとめと明日やることを記録

      
週末に「今週の振り返り」→ 来週の優先3つまで出してくれる

      
作業を再開したい「昨日の続きやろう」「今の状況教えて」

      
覚えておいてほしい「これ覚えておいて：〇〇」

      
AIが間違えた「それ違う、〇〇して」→ mistakes に残って、次から気をつける

      
記憶がごちゃごちゃしてきた「記憶を整理して」（月1回くらいがおすすめ）

    

  

  

    
🧠 賢く育てるコツ

    
    
      
  • Codex は必ず AI-Brain フォルダを開いて使う（別のフォルダで開くと記憶を読みません）
    • 
      
  • ミスは遠慮なく指摘するのがいちばん効きます
    • 
      
  • about-me.md は自分で書き足してOK。仕事・目標・苦手なことなどを書くほど、話が早くなります
    • 
      
  • secretary.md を書き換えると秘書のキャラが変わります（名前・話し方・口ぐせなど。すぐ反映したいときは「secretary.md 読み直して」）
    • 
      
  • AGENTS.md を書き換えると AI の動きが変わります（例：「返事は3行以内で」と足す）
    • 
      
  • Obsidian のグラフビューで記憶のつながりを眺めると楽しいです
    • 
    

  

  
⚠️パスワード・APIキー・カード番号は記憶に書かせないでください。お客さんの個人情報も必要最低限にしましょう。







  
06
困ったとき

  
基本は、症状をそのまま Codex に伝えれば直してくれます。よくあるものだけ載せています。


  

    Codex が「手順書を読めない」と言う
    

      
ネットへのアクセスが許可されていない可能性があります。許可を求められたらOKしてください。それでもダメなら、03 の一番下の「手順書をダウンロード」で保存して、「ダウンロードフォルダの obsidian-codex-setup.md を読んで進めて」と送ってください。

    

  


  

    新しいセッションで、前回のことを覚えていない
    

      
いちばん多い原因は、別のフォルダを開いていることです。Codex で開いているフォルダが AI-Brain になっているか確認してください。合っているなら「AGENTS.md の記憶のルールを読んで、今の状況を教えて」と送ってみてください。

    

  


  

    「フォルダの場所がよくない」と止められた
    

      
「書類」や「デスクトップ」そのものを開いていると止まるようになっています。02 の STEP 1 で新しいフォルダを作り、そのフォルダを Codex で開き直してから、もう一度このページのURLを貼ってください。

    

  


  

    Obsidian に何も表示されない
    

      
別のフォルダを保管庫として開いている可能性があります。Obsidian の左下の保管庫アイコン →「フォルダを保管庫として開く」から、AI-Brain を選び直してください。

    

  


  

    ファイルを作るたびに「許可しますか？」と聞かれる
    

      
Codex が「毎回確認する」設定になっています。そのままでも使えます（そのつど許可すればOK）。面倒なときは「毎回の確認を減らしたい」と Codex に伝えると、設定の変え方を案内してくれます。

    

  


  

    自動で記録してくれない
    

      
「今の内容を daily に記録して」と頼めば確実に記録されます。何度も忘れるようなら「記録を忘れないように AGENTS.md のルールを強めて」と頼んでみてください。

    

  


  

    別のフォルダで作業するときも、この記憶を使いたい
    

      
AI-Brain を開いた Codex に「他のフォルダでもこの記憶を使えるようにして」と頼んでください。手順書の付録どおりに、Codex 全体の設定（~/.codex/AGENTS.md）に記憶フォルダの場所を書き足してくれます（書き足す前に確認があります。前からある設定は消しません）。

    

  


  

    Claude Code 版で作った記憶フォルダを、Codex でも使いたい
    

      
その記憶フォルダ（例：Claude-Brain）を Codex で開いて、このページのURLを貼ってください。Codex が見つけて、今の記憶はそのままで AGENTS.md だけ足してくれます（CLAUDE.md は触りません）。Claude Code と Codex で同じ記憶を共有できますが、同じ時間に両方で作業しないのがおすすめです。
